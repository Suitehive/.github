# Getting help

- **Documentation:** start with the website docs (Getting started, the admin guide and Troubleshooting).
- **Questions and ideas:** open a GitHub issue in [suitehive](https://github.com/Suitehive/suitehive) with the
  `question` label. Discussions will open once the project is public.
- **Bugs:** use the bug report template in the repository the bug belongs to.
- **Security issues:** never in public. See the [security policy](SECURITY.md).

Suitehive is built by a small team, so replies may take a few days. Clear steps to reproduce and the
output of `suitehive status` help us answer much faster.
